# PDF Screenshot Helper

A powerful Chrome extension that streamlines the process of capturing multiple screenshots of a specific area on a webpage and compiling them into a professional PDF document. Perfect for creating documentation, tutorials, step-by-step guides, or archiving sequential content from web applications.

## What It Does

**PDF Screenshot Helper** allows you to:
- **Select a capture area once** - Define a specific region on any webpage that you want to repeatedly screenshot
- **Capture with a keyboard shortcut** - Use `Ctrl+Shift+S` (Mac: `Cmd+Shift+S`) to instantly capture the same area without needing to reselect it
- **Compile into PDF** - Automatically generate a clean, full-bleed PDF with all your screenshots, perfectly sized to match your capture area
- **Handle large batches** - Split extensive screenshot collections into multiple PDF files for better reliability and performance
- **Maintain high quality** - Automatically handles high-DPI displays to ensure crisp, sharp screenshots at native resolution
